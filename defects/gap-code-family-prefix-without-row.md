title = "A gap code under a registered family prefix has no row, meaning or repair of its own"
state = "open"
since = "v0.2.0-beta.11"
fixed_in = ""
workaround = "none"
+++

A gap code under a registered family prefix counts as registered without a row of its own, so the
statement in the entry of 0.2.0-beta.11 that every code has its row holds for the rows and the
families together. A refusal with such a code carries no meaning and no fixed repair from the table.
