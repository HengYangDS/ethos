# npm Distribution Adapter

Status: active.

Purpose: provide a thin npm launcher for hosts that prefer Node package
installation while keeping Python ETHOS as product truth.

See also: `docs/architecture/distribution.md`.

The npm distribution is a thin launcher for the Python `ethos` command plane.
It is not a second implementation and does not own ETHOS product semantics.
