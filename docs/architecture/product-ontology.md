# Product Ontology

ETHOS keeps one thin command package and five semantic product packages:

```text
ethos
ethos-kernel
ethos-governance
ethos-workspace
ethos-agent
ethos-adopt
```

Top-level packages are derived shells over the kernel. Runtime, proof, quality,
spec, campaign, intake, and host concerns are modules inside those packages, not
top-level product identities.
