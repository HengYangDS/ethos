# Kernel Model

Status: canonical.

Purpose: define the ETHOS kernel chain that higher-level command and quality
surfaces project from.

See also: [Package Ontology](../architecture/package-ontology.md) and
[Glossary](../reference/glossary.md).

ETHOS reduces repository operation to:

```text
Constitution -> Subject -> Commitment -> Change -> Evidence -> Chronicle -> Evolution
```

`Subject` scopes the governed object. `Commitment` unifies contracts, specs,
policies, claims, rules, and decisions. `Change` carries IR, transition, and
inscription. `Evidence` binds proof, gate, digest, and HEAD facts. `Chronicle`
keeps judged memory. `Evolution` records campaigns, hypotheses, experiments,
canonization, and retirement.
