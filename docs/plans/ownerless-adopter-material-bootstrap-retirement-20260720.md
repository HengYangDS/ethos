## Authority and boundary

After this carrier has passed its own exact-HEAD local lifecycle and accepted
closeout, its Chronicle may support one native `lane_resolution/retire`
decision for this exact clean source only. The native resolver must bind a
fresh linked-worktree observation, exact ref SHA, Chronicle bytes, reason,
recovery plan, break-glass, irreversible confirmation, and receipt.

This carrier does not authorize any other lane, any active lease takeover,
preservation as a substitute for absorption, raw Git deletion, GitHub/GitLab
mutation, or a hosted-CI claim.

## Recovery

Git history at the exact source SHA remains the recoverable historical record.
If the source ref, cleanliness, link binding, accepted semantic evidence, or
control-plane state drifts, native retirement remains blocked and no ref is
deleted.
