# Change Surfaces

Status: active research; findings are inputs, not accepted product behavior.

Purpose: find the evidence behind the names and forms through which a change meets a forge and
its readers: branch names, issue forms, the description of a pull or merge request, and the
marks of who wrote a change, with what coding agents add to each.

See also: [Research](../README.md) and
[Direction carriers](../direction-carriers/README.md), whose practice study covers proposals,
roadmaps and intake as processes; this topic covers their surfaces on a forge.
