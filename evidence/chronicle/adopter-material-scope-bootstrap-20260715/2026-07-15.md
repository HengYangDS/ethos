# Adopter material-scope bootstrap — 2026-07-15

## Observation

The accepted material-scope contract correctly blocks unscoped material work,
but a valid adopted profile created before the contract cannot add the first
`[openspec].material_paths` declaration through the ordinary coverage rule.

## Decision under test

ETHOS recognises only the exact tracked `.ethos/profile.toml` write while the
declaration is absent and exactly one official active Change is selected. The
result is bootstrap provenance, not coverage. Afterward the profile must use
the ordinary exact Change-local `scope.toml` bootstrap and all later material
writes are checked normally.

## Local verification

The focused scope suite passed with 20 tests, including the permitted write and
empty, malformed, untracked, widened, and multiple-Change rejection cases. The
repository Python format/lint owner gate and the official strict OpenSpec plus
ETHOS lifecycle projection also passed before closeout. These are local
observations; they are not a claim of remote publication.

## Boundary

This evidence does not claim that empty or malformed declarations are valid,
that a profile write covers adjacent files, that any adopter is closed, or that
candidate landing, accepted closeout, local installation, GitLab publication,
or GitHub mirroring has occurred. The archive, executed proof, and promotion
remain separate transitions.
