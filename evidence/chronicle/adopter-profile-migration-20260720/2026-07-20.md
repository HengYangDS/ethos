# Adopter Profile Migration Observation

Date: 2026-07-20.

## Fact

An existing documentation adopter used the former profile envelope and
`roots.rules = "."` to express a root-level normative source. The current
strict profile declaration rejected that profile, and public commands leaked
the resulting `ValueError` as a traceback.

## Evidence

- The focused profile and JSON-boundary regression suite passed after adding
  bounded former-envelope normalization, top-level `normative_sources`, and
  public invalid-profile result translation.
- Direct CLI probes verified structured JSON for `orient`, `report`, `plan`,
  `openspec --lifecycle`, and enforcing `prove`; no probe emitted a traceback.
- Official OpenSpec validation accepted the active Change.

## Boundary

This observation proves ETHOS product behavior in the current Work Lane only.
It does not claim that DDWG has migrated, that a proof has been executed on a
future product HEAD, or that any local or hosted publication has happened.
