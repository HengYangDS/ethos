# Adoption Scaffold Semantic Package Evidence

Date: 2026-07-09

This chronicle records the Work Lane `work/adoption-scaffold-semantic-20260709`.
The lane retires adoption scaffold suffix-flat residue by replacing
`ethos.repository.adoption.scaffold.py`, `scaffold_docs/`, and
`scaffold_openspec.py` with a semantic scaffold package:

- `ethos.repository.adoption.scaffold.core` owns the adoption file builder and
  public `default_files` contract;
- `ethos.repository.adoption.scaffold.openspec` owns OpenSpec scaffold text;
- `ethos.repository.adoption.scaffold.decisions.core` owns decision-record
  templates;
- `ethos.repository.adoption.scaffold.documents.pages` owns documentation-page
  templates;
- `ethos.repository.adoption.scaffold.skills.core` owns skill-package templates.

No compatibility import shell, re-export facade, package-root barrel, or lazy
forwarder is retained. Callers now import concrete defining modules. The former
cross-module private helper use `_default_files` was promoted to the explicit
public contract `default_files` because adoption planning uses it outside the
scaffold defining module.
