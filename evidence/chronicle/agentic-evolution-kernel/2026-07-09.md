# Agentic Evolution Kernel Evidence

## Judgment

This evidence records the design substrate for governing external agentic issue
intake, managed-agent platforms, automation canvases, coding-agent runtimes, and
bounded repository evolution boundaries.

The design preserves the ETHOS kernel:

```text
Authority -> Subject -> Commitment -> Change -> Evidence -> Claim -> Chronicle
status -> plan -> prove -> land -> publish
```

External tools remain adapters or projections. They may perceive, render,
schedule, route, and execute. ETHOS governs admission, proof, claim, chronicle,
land, and publication-readiness transitions. Remote publication and release
require the configured human or release authorization.

The July 9 design iteration further calibrates this boundary against Multica,
GitHub Copilot coding agent, OpenHands Agent Canvas / Resolver, GitLab Duo Agent
Platform, SWE-agent, and Beads-like task graphs. The accepted lesson is not to
copy their lifecycle grammar. The accepted lesson is to separate sensing,
issue projection, execution backend, result import, proof, claim, chronicle, and
upstream guardrail generation.
