# Audit Semantic Subpackages

## Claim

ETHOS moved the repository design-integrity audit and repository OpenSpec audit
from root-level suffix-flat modules into semantic subpackages without compatibility
import shells or package-root re-export facades:

- `packages/ethos/src/ethos/repository/design/integrity.py`
- `packages/ethos/src/ethos/repository/openspec/audit.py`

The existing `ethos.repository.audit` module remains the repository audit
composition module. The migration therefore does not create a conflicting
`ethos.repository.audit` package and does not preserve old import paths.

## Boundary

This is a module-layout hardening step only. It does not claim that all remaining
module-layout debt is gone; remaining debt is still tracked by
`.config/checks/module-layout/policy.toml`:

```text
baseline_gap_limit = 5
baseline_suffix_module_limit = 4
baseline_flat_directory_limit = 1
```

The remaining suffix module and flat CLI directory debts are future work. They
must be retired by semantic subpackages, not by compatibility facades, suffix
renaming, package-root barrels, or lazy forwarding.
