# Authorization And Admission Boundary Evidence — 2026-07-10

## Claim

ETHOS now separates truth-source precedence, action-specific admission, local
Work Lane coordination, transition enforcement, and durable exceptional
judgment without introducing an ETHOS-owned identity or permission registry.

## Boundary

This evidence covers the implemented local product boundary: normalized leases,
exact mutation envelopes, cross-host handoff, bounded external evidence,
protected control-replacement bootstrap, two-phase exceptional resolution, and
semantic nested Lane commands. It does not claim hosted enforcement or remote
publication. Accepted-root closeout and owned-lane retirement remain separate
final lifecycle transitions recorded after archive and final proof.

## Design Judgment

- `Authority` ranks conflicting truth sources; it does not authenticate callers
  or issue permissions.
- A mutation decision is an exact-request evaluation over applicable
  Commitments, current repository and Git facts, and bounded Evidence.
- Intent, confirmation, authorization, admission, and enforcement remain
  separate facts.
- External human, workload, or agent identity is verified only when a
  Commitment requires it. ETHOS stores the minimum issuer-qualified evidence,
  not a Principal, Agent, Session, Team, Party, or account registry.
- A Lane Lease coordinates one current local writer in one Git common
  directory. It is neither a distributed lock nor a filesystem fence.
- Shared multi-clone serialization occurs at mediated Git ref transitions.
- Chronicle retains exceptional judgments that must survive local-state loss;
  routine lease telemetry remains local.
- Candidate controls cannot approve their own replacement. Incumbent or
  candidate-external bootstrap provenance is required.
- The protected bootstrap verifier binds accepted/candidate heads, control-tree
  digests, verifier digest, candidate proof, and a bootstrap Chronicle decision;
  a caller-authored six-field JSON receipt is rejected.
- Cross-host import restores preserved tracked and non-ignored untracked work
  and rolls back branch/worktree residue if destination lease creation fails.
- Exceptional resolution consumes an accepted Chronicle reference, recovery
  plan, and observation digest covering tracked and untracked content.
