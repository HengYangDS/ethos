## Reproduced Root Cause

`workspace_status(..., include_foreign_path_scope=False)` intentionally selects
the bounded read model. `coordination_package` currently derives detail state
from `any(lane.scope_state == "deferred")`. With zero foreign lane rows,
`any([])` is false, so the output incorrectly claims exact detail and emits five
zero aggregates for detail the bounded caller did not inspect.
