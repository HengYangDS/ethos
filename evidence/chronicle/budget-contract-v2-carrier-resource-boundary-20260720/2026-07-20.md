# Budget Contract v2 Carrier Resource Boundary

## State

Active authoring carrier. No implementation, proof, archive, land, closeout,
publication, or retirement claim is made by this record.

## Decision

Before immutable Git replay or v2 activation, Budget Contract v2 will bind one
versioned execution contract to every metric/provider atom. The first admitted
mode is `bounded_in_process_v1`: `utf8-footprint` is capped at 262,144 bytes,
`python-tokenize` at 65,536 bytes, and every other current provider, including
`utf8-control`, at 32,768 bytes. The values are fixed provider contracts, not
derived allowances or per-path exceptions.

Metric registry wire and atom versions advance to 3. The execution mode and
ceiling enter provider descriptors and every downstream observation identity.
The descriptor reader must resolve the contract before opening content, reject
pre-read oversize objects before `os.read`, retain at most `limit + 1` bytes,
and preserve all existing no-follow and fingerprint checks. Direct native bytes
must be rejected before startup conformance, decoding, AST, or parsing.

## Read-Only Compatibility Observation

The accepted Task 3 head classified 2,880 measured carriers and three reviewed
exclusions with no inventory gap. Current maxima were 201,661 bytes for
`utf8-footprint`, 34,267 bytes for Python, 22,397 bytes for TOML, 12,255 bytes
for JSON, 11,472 bytes for shell, 7,973 bytes for YAML, and 609 bytes for the
largest control carrier. These observations show compatibility only; they did
not calculate or raise the ceilings.

## Fallback And Stop Conditions

V1 remains authoritative and v2 remains inactive. If independent security
review rejects the byte-ceiling design, this Change cannot close and must
implement a versioned one-shot isolated worker with memory, CPU, wall,
descriptor/process, protocol, and output limits and no in-process fallback.
Any path override, automatic limit growth, partial snapshot, changed v1
allowance/debt/terminal/ELOC rule, weakened YAML graph safety, or replay/policy/
cutover behavior is a stop condition.
