# Semantic Package Build Artifact Chronicle

## Claim

ETHOS package builds write only to the semantic local-artifact home
build/artifacts/python; neither the product proof gate nor contributor
guidance relies on the repository-root dist/ default.

## Trigger Signal

A full-proof run executed the build gate as uv build --all-packages. The
command succeeded but wrote ignored wheel and source distributions under dist/,
which the generated-artifact contract correctly classifies as a retired
generated home.

## Evidence

- Focused governance and documentation tests first failed against the bare build
  command and then passed after the semantic output route was declared.
- The product gate declaration and packaged registry projection now invoke
  uv build --all-packages --out-dir build/artifacts/python --clear
  --no-create-gitignore. The suppressed marker is redundant because the
  repository-level build/ ignore already owns the generated-artifact boundary;
  it also removes the concurrent workspace build race over an output-local
  .gitignore.
- A direct execution of that command produced the two wheel and two source
  distribution artifacts only under build/artifacts/python/.
- ethos quality generated-artifacts --json was clean after removal of the
  disposable legacy dist/ residue.
- The focused regression suite, configuration and CI-projection checks, and a
  20-run deterministic build stress passed. A HEAD-bound full proof at
  c572b04fa3bc38817df7058bda1e407e06255ba3 passed all 28 gates, with evidence
  digest d0bf2d23e03f7211c46922ee473348dc0166efc7140f0a229c8ef1ca51ebfebc.
- The official OpenSpec archive command moved the completed carrier to
  openspec/changes/archive/2026-07-11-build-artifact-topology-contract
  and synchronized the accepted repository-governance specification.

## Boundary

This is local, historical implementation evidence. It does not assert current
HEAD proof after the recorded verification, hosted CI success, remote
publication, or permission to retain generated artifacts as repository truth.
