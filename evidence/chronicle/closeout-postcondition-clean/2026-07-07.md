# Closeout postcondition clean

ETHOS made clean accepted-root status an explicit postcondition for
`accepted_validated`. After accepted-ref CAS and worktree sync, closeout now
checks `git status --short`; any remaining dirty state becomes
`accepted_worktree_dirty_after_sync` instead of a false success.

ETHOS also moved OpenSpec active-carrier legality into mutation admission. A
completed Work Lane carrier left under `openspec/changes/<id>` blocks land, and
any active carrier present in candidate or accepted-root truth blocks closeout.
This closes the adapter-level bypass where audit could see the small signal but a
transition could still proceed if called below the CLI aggregation layer.
