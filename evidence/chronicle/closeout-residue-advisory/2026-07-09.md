# Closeout Residue Advisory Chronicle

## Claim

ETHOS status and report now expose closeout residue as a thin advisory
read-model over each foreign Work Lane. The model adds accepted-root relation
and one closeout disposition derived from existing Git, dirty-state, lease, and
claim facts. The change does not authorize mutation over foreign Work Lanes and
does not add a new truth store, package, or command plane.

## Trigger signal

During multi-agent closeout, landed lanes, missing-lease lanes, dirty landed
lanes, unlanded lanes, and diverged lanes were visible only after inspecting
lane status details. Report-level advisory signals made foreign lanes visible
but did not distinguish which lanes needed closeout disposition.

## Net gain

- Reveals closeout disposition on `foreign_work_lanes[]` without changing
  transition semantics.
- Keeps missing leases distinct from retire-ready closeout disposition.
- Keeps foreign Work Lanes observe-only by default.
- Routes repair hints to read-only `ethos orient --json` and
  `ethos lane status --json`.
- Extends the existing workspace-status schema rather than creating a parallel
  coordination store or branch-level gap taxonomy.

## Boundaries

This evidence does not claim remote CI, remote publication, or authority to
retire another actor's Work Lane. It only claims a repository read model and
scorecard advisory projection. Branch-level closeout details remain on the lane
read-model; `coordination.advisory_gaps` carries only the coarse residue
signal plus existing missing-lease signals.

## Refresh-base admission regression

During closeout, `ethos lane refresh-base --apply --authorize` exposed a
mechanism gap: Git rebase temporarily detaches HEAD, causing the pre-commit
admission fallback to see `role=detached` and block ETHOS' own sanctioned Work
Lane replay. The fix keeps the hook fail-closed by deriving an effective
`work_lane` role only from Git rebase `head-name` when it names a configured
`work/*` branch; all other detached replay remains protected.
