# Closeout worktree sync

A live closeout pattern exposed a hidden projection gap: accepted-root closeout
could return `accepted_validated` while the accepted worktree/index still showed
old-tree D/M residue. The fix keeps `update-ref` as the accepted-ref CAS, then
performs a checked hard reset to the candidate head under the sanctioned closeout
environment. Because accepted-root dirty state is a pre-closeout blocker, this
sync cannot discard admitted user edits.
