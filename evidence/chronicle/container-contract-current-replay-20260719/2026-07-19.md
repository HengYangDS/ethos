# Container Contract Current Replay — 2026-07-19

## Source Assessment

The ownerless 2026-07-13, 2026-07-14, and 2026-07-15 container-contract lanes
contain a genuine adopter-validation capability that is absent from the accepted
product. Their branch topology and prior source-budget carrier are historical
evidence only; no historical branch is merged by this replay.

## Current Decision

The current owned lane restores the capability as a profile-opt-in,
provider-neutral contract. Product-owned schemas validate the declaration and
manifest. A thin adapter adds containment, Git tracking, digest, architecture,
asset-recovery, output-schema, and provider-neutral naming checks that JSON
Schema alone cannot prove. Declared failures flow through the existing schema
report rather than a new command or proof lifecycle.

## Replay Verification

The initial focused test was intentionally run before the validator existed and
failed with `ModuleNotFoundError` for the absent container-contract module.
The current fixture matrix, schema-report integration, schema-governance tests,
and invalid-state taxonomy tests are green on this owned lane. This confirms
the replay changes current product behavior; it does not turn a historical
source branch into a merged carrier.

## Evidence Boundary

The local test matrix proves product validation semantics for miniature adopter
repositories. It does not prove an OCI build, a native Linux runtime, hosted CI,
remote publication, or any particular adopter's deployment.

## Retirement Boundary

No source lane is retired by this carrier alone. Each source retains its exact
head and current worktree state until this carrier is proven and accepted, then
a fresh per-target resolution decision records whether the source was absorbed,
preserved, or remains blocked.
