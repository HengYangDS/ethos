# DDWG Legacy Profile Bootstrap Bridge Observation

Date: 2026-07-20.

## Fact

DDWG accepted-root closeout was blocked because its complete historical adopter
profile uses `roots.rules = "."`, while the current strict typed contract
rejects repository-root paths. DDWG's candidate already carries the canonical
`normative_sources = ["guidelines.md"]` form, but the accepted root must first
parse successfully to audit that candidate.

## Evidence

- The official OpenSpec Change defines one bounded modification to
  `repository-governance`.
- Focused profile-contract tests passed for the complete legacy bridge, an
  explicitly declared legacy normative source, and rejection of the workaround
  in a current declaration.
- Strict official OpenSpec validation passed for this Change.
- A checkout-bound probe loaded DDWG's existing accepted profile as a valid
  typed declaration with `rules = "rules"` and
  `normative_sources = ["guidelines.md"]`.

## Boundary

This observation proves only the product-side parser bridge in its owned Work
Lane. It does not prove product landing, accepted-root closeout, DDWG
promotion, runner deployment, remote publication, hosted CI, or recovery of a
Desktop conversation.
