# Evidence Run Isolation Chronicle

## Claim

ETHOS serializes shared generated coverage evidence writes so concurrent local
proof and CI fallback runs cannot corrupt the latest coverage artifact.

## Trigger signal

During local closeout, running `tools/ci/scripts/run-python-tests.sh` and
`ethos prove --execute` concurrently made the Python tests pass while coverage
reported a false low total. Re-running the same gate sequentially returned
`1266 passed` with `100.00%` coverage. The failure was therefore a physical
evidence-boundary race, not a semantic test failure.

## Net gain

- Preserves the existing generated evidence root and latest coverage artifact.
- Adds only a small POSIX lock around a shared write boundary.
- Makes the proof/local-CI path deterministic under multi-agent operation.
- Keeps hosted CI and local fallback as projections over the owner script.
