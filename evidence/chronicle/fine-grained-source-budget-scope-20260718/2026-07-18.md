# Fine-Grained Source-Budget Scope — 2026-07-18

## Decision

`ethos quality source-budget --json` remains the global measurement and debt
contract. It is removed from the default promotion proof because that proof
answers whether one current Change is locally correct and governable; it does
not settle repository-wide compression debt.

## Boundary

The full proof and global compression closeout still require a clean
source-budget report. The scorecard retains every source-budget gap in a
separate advisory `global_compression` layer with a direct repair action. This
decision neither changes an allowance, baseline, terminal target, or debt cap
nor retires a Work Lane.
