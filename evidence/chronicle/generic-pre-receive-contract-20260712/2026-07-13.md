# Generic pre-receive contract evidence — 2026-07-13

## Judgment

ETHOS now supplies a physically extension-local, provider-owned generic Git
pre-receive reference adapter. The adapter remains default-off. Its control
plane is one protected TOML file outside a governed repository, so a normal
adopter needs neither an account, signing key, receipt store, daemon, network
service, nor `yheng-agent-ethos`.

For configured protected non-deletion refs, the adapter resolves only the
proposed tree with a fixed Git binary. It verifies a provider-store receipt's
payload digest, SSH signature, freshness, and exact remote, commit, tree,
action, proof-floor, policy, and implementation bindings. It never evaluates a
pushed configuration, executes client input, or makes a network call.

## Local verification

- Focused fail-closed tests cover disabled mode, unprotected refs, an exact
  protected update, missing, unsigned, digest-damaged, stale, deletion, and
  tree/policy/proof-floor-mismatched receipts.
- Default pytest discovery includes the extension-local focused test surface.
- Ruff, formatting, and TOML configuration validation cover the added source,
  test, manifest, and configuration discovery path.

## Boundary

This is digest-bound local implementation evidence. It does not assert hosted
forge execution, remote publication, semantic correctness, authority, or a
required independent-verifier deployment. Full HEAD-bound proof, archive,
claim rebinding, candidate landing, and local publication readiness remain
separate transitions.
