The preceding single-proof change remains correct. Its removal of GitHub's
redundant standalone test step exposed that the pre-proof report had been
accidentally consuming coverage from the duplicate step.

## Decision

`audit -> prove -> report -> combine`. Add a behavioral regression test that
executes the real script with controlled producer state. Do not restore duplicate
tests, weaken the receipt, rerun the unchanged failed job, change timeouts or
workers, or add retries.
