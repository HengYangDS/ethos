# Intake Mine Read Model Evidence

## Judgment

This evidence records the first implementation slice after the Agentic Evolution
Kernel design: ETHOS can mine repository-local signals into intake envelopes and
issue candidates without creating external issues, mutating a Work Lane, or
dispatching agents.

The boundary remains:

```text
Signal != Issue
Issue != Change
Agent output != Truth
Execution != Proof
```

`ethos intake mine --json` is therefore a perception/read-model surface. It
returns `repository_truth=false`, records no writes, and marks every generated
candidate with `auto_raise_allowed=false` and `auto_dispatch_allowed=false`.
