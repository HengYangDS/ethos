# Invalid-State Release Resource Evidence

## Judgment

`system/invalid_states.toml` remains the invalid-state taxonomy SSOT. Installed
`ethos-core` wheels now carry `ethos_core/data/invalid_states.toml` as a release
mirror so the taxonomy remains available outside a source checkout.

The packaged mirror is not a new truth center: tests parse both TOML files and
require equality, and runtime loading prefers the source contract when present.

## Evidence

- `uv run --all-packages pytest tests/unit/kernel/test_invalid_states.py -q`
  returned `11 passed`.
- `uv build --package ethos-core --wheel --out-dir /tmp/ethos-core-build-check`
  succeeded.
- Wheel inspection found `ethos_core/data/invalid_states.toml` in
  `ethos_core-0.1.0a1-py3-none-any.whl`.

## Boundary

This change improves release substrate trust. It does not add a new
invalid-state category, command, OpenSpec surface, or runtime truth store.
