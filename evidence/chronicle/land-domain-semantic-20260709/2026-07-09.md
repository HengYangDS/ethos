# land-domain-semantic-20260709

## Claim

ETHOS land-stage domain reducers were moved from suffix-flat modules into a semantic `ethos.domain.land` subpackage without compatibility facades or package-root re-exports.

## Design boundary

- Removed `packages/ethos/src/ethos/domain/land.py` and `packages/ethos/src/ethos/domain/land_support.py`.
- Added semantic modules under `packages/ethos/src/ethos/domain/land/`:
  - `core.py` for land/closeout lifecycle, runner binding, and audit handoff.
  - `publication.py` for publish readiness and local-CI fallback read models.
  - `intake/core.py` for intake-ledger projection.
  - `parity/core.py` for parity evidence freshness reducers.
  - `trust/core.py` for trust closeout reducers.
- Package `__init__.py` files remain docstring-only.
- Callers import concrete defining modules; no compatibility import shell was kept.
