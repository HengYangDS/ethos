# Work Lane Public Primitives Evidence — 2026-07-09

## Claim

ETHOS stopped sharing Work Lane lifecycle helpers by importing private sibling
symbols from the former suffix-flat `ethos.adapters.mutation.lanes_retire` module. Shared Git, repository-root,
ancestor, slug, and default-path primitives now live in the semantic subpackage
`ethos.adapters.mutation.lane_lifecycle.core`, and callers import those public
symbols directly.

## Net gain

- Removes the concrete `from ethos.adapters.mutation.lanes_retire import _...`
  dependency path from lane start, refresh, and retire code.
- Keeps package roots declaration-only; no compatibility re-export shell or
  `__all__` alias surface was added.
- Moves helper reuse toward a named semantic subpackage instead of suffix-flat
  helper modules or private sibling reach-through.
- Hardens `ethos quality module-layout --json` with a changed-file regression
  check for `from ... import _private` imports, so future touched product modules
  cannot introduce the same private-symbol dependency pattern through normal
  quality gates.

## Boundaries

`ethos quality module-layout --json` still reports tracked baseline debt for

from-import debt outside the touched files remains future semantic-subpackage
backlog. This lane prevents the same pattern from reappearing in changed files
and removes it from the Work Lane lifecycle helper path.

This evidence is local repository evidence only. It does not claim remote push,
hosted CI, or remote publication.
