# Minimal Semantic Docs Topology Evidence — 2026-07-08

## Claim

ETHOS documentation topology now classifies semantic role and authority instead of
`current`/`future` lifecycle time. The common governed docs kernel is
navigation, decisions, evidence, history, and reference. Present repository
truth is bound to HEAD, authority order, proof, evidence, and claims; unlanded
intent is carried by OpenSpec changes, plans, research, or decision revisit
triggers.

## Scope

- Removed `current`/`future` roots from the required docs topology contract.
- Rejected `current` and `future` as docs front matter `state` values.
- Kept contract/evolution labels out of the common required kernel while
  allowing product or domain extension roots to remain optional.
- Updated adoption scaffold to generate the minimal semantic docs kernel while
  keeping onboarding and ETHOS governance pages as explicit extension docs.
- Updated generated-artifact policy to deny generated drift under governed docs
  generically instead of naming each governed docs subdirectory.
- Hardened the Python test owner script so trust-bearing coverage runs
  clean stale generated coverage, JUnit evidence, and root `.coverage*`
  residue before pytest/xdist starts and after it exits.
- Bound coverage.py's default data file to the declared build evidence path
  so interrupted local runs do not mint root-level generated artifacts.
- Bounded the default local pytest worker count to eight instead of host-wide
  auto discovery so owner-script proof remains deterministic under local load.
- Isolated pytest/xdist proof records into worker-local ignored state while
  preserving production proof records under `.ethos/state/proof`.
- Isolated closeout temporary git commits from ambient commit signing without
  weakening real repository signing-policy checks.
- Preserved command-surface policy selectors as `governed_docs` and
  `governed_doc_globs`.
- Added DR-0004 and superseded DR-0002 while preserving historical record text.
- Added an archived OpenSpec carrier at
  `openspec/changes/archive/2026-07-08-native-docs-topology`.
