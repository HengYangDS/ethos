# Node Runtime Compatibility — 2026-07-16

## Archive

Official OpenSpec archive completed on 2026-07-16. The immutable carrier is
`openspec/changes/archive/2026-07-16-node-runtime-compatibility-20260716`.

## Decision

ETHOS keeps layered Node ownership. The repository proves its npm launcher on
exact Node 24.18.0 and 26.5.0 releases while hosted packaging remains on Node
24.18.0. Workstation, IDE, desktop, and application-managed runtimes keep their
own authorities and are not rewritten by this change.

Node 26.5.0 is the next default candidate. October 28, 2026 is an earliest
review trigger, not an automatic promotion date. A later reviewed change must
check current official release status, hosted results, package evidence, and
rollback readiness before changing the default.

## Evidence

- `.config/checks/node/runtime.toml` owns the exact versions, review boundary,
  and official Linux x64/arm64 archive SHA-256 values.
- `tools/ci/scripts/install-node.sh` verifies the selected archive against the
  pinned policy value before extraction.
- `tools/ci/scripts/run-node-compatibility.sh` rejects undeclared or mismatched
  Node releases before npm acceptance runs.
- GitLab projects the policy as an exact two-release matrix through its tracked
  template; the package job keeps the installer default.
- Architecture contracts bind the policy to the installer default, archive
  checksum coverage, and parsed CI matrix; they exercise the runner command
  order and engine-strict environment and fail before npm on a runtime mismatch.
- Local Linux arm64 containers executed the launcher and package dry run on Node
  24.18.0 and 26.5.0. Both official Node archives bundled npm 11.11.0.
- Config, Shell, CI-template, strict OpenSpec, focused pytest, and quality-owner
  checks are part of the proof command set recorded by the claim.

## Boundaries

- Local Docker execution is not hosted GitLab evidence.
- `packageManager = "npm@11.12.1"` is preserved but was not provisioned or
  proved. Package-manager supply and enforcement require a separate change.
- The npm launcher retains its existing `engines.node >=20` compatibility floor;
  the exact matrix is acceptance evidence, not a narrowed package declaration.
- No repository claim authorizes replacement of a JetBrains-, desktop-, or
  application-managed Node runtime.
- The initiating cause of the earlier Copilot cancellation is unrelated and
  remains unverified; this repository change does not claim to repair that
  external product.

## Fallback And Kill Signal

Fallback is the unchanged Node 24.18.0 package default and single-release hosted
path. Revert the compatibility change if either exact runtime cannot execute the
launcher and package dry run, if CI stops projecting the policy exactly, or if
an official archive fails its pinned checksum, or if compatibility work begins
mutating separately managed runtimes.
