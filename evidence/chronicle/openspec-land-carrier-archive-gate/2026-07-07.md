# OpenSpec Land Carrier Archive Gate

## Judgment

A Work Lane may use `openspec/changes/<id>` as authoring carrier, but land is a
promotion boundary. Active OpenSpec carriers must be archived/fused before land
so stale intent cannot enter candidate truth.

## Evidence

- RED: `uv run --group dev pytest tests/unit/coverage/test_core_state_claims_edges.py::test_mutation_admission_blocks_any_active_openspec_carrier_before_land -q`
  failed because land admission returned no gap for active carrier `wip`.
- GREEN: focused regression and existing completed-carrier regression passed
  after `_openspec_carrier_gaps` began blocking active Work Lane carriers at land.

## Boundary

This change adds no truth store and no command surface. It strengthens the
existing OpenSpec carrier boundary inside mutation admission.
