# OpenSpec lifecycle protected advisory evidence

`ethos openspec --lifecycle --json` now surfaces active OpenSpec carriers found
in non-current protected branch Git trees as advisory state. On the live ETHOS
repository it reports the `main` release-root `ethos-release-hardening` carrier in
`data.advisory_gaps` and `data.lifecycle.protected_branch_residue` while keeping
`required_gaps` empty for the clean current checkout.

## Boundary

This evidence supports reader visibility only. It does not mutate `main`, retire
foreign Work Lanes, add a command plane, or turn non-current protected-branch
signals into current accepted-root blockers.
