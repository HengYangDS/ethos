## Facts

Canonical Ruff policy ignores T201 for repo-local skill scripts. Replaying the
recorded ordinary Ruff command against the pre-change files passes, so the
accepted skill-script carrier's claim that current Ruff rejected those print
calls was false. Its active Claim, plan, duplicate accepted-spec scenario, and
style-only script changes must be removed through a forward revert.

The source preserve-retire effect did create and verify a package, but it wrote
the package and receipt below the invoking carrier's ignored build tree.
Ordinary carrier retirement then removed that worktree. No
lane_resolution/clear-preservation receipt exists. The old package, receipt,
and original bundle are not currently available and are not claimed as
retained.

The original tracked patch remains available as 9,673 bytes and matches the
recorded SHA-256. The source commit remains reachable. Those facts permit a new
bounded recovery transition, not recreation of the deleted historical receipt.

## Decision

First, forward-revert the invalid six-commit range through an owned lane. Then
change resolution storage so new recovery artifacts belong to the accepted
checkout's sibling records owner, while legacy retained manifests block
ordinary worktree retirement.

Only after this successor is archived, exactly proven, landed, and locally
accepted may a distinct temporary recovery lane be created from the recorded
source commit and exact patch. This Chronicle then authorizes one new
lane_resolution/preserve-retire decision for that recovery lane. The decision
must use new identifiers, reobserve the exact new branch/head/diff, write to the
stable records owner, and remain discoverable after the recovery lane is gone.

## Implementation and proof boundary

The successor implementation writes new decisions, preservation packages,
completion receipts, and clear receipts below the configured accepted
checkout's sibling `recovery/lane-resolution` records owner. Legacy stores
remain read-only compatibility inputs across registered worktrees. New decision
writes cannot target those legacy or foreign-worktree roots.

Canonical and legacy content conflicts block with
`lane_resolution_decision_record_conflict`. Ordinary retirement of a worktree
that still contains a retained legacy manifest blocks with
`lane_resolution_legacy_retention_present`. If a destructive source effect
completes but immutable receipt writing fails, the result is `ok=false`,
`state=partial_transition`, with
`lane_resolution_receipt_write_failed_after_effect`; the stable decision and
package remain available for reconciliation.

Independent review additionally required unique no-clobber decision paths,
canonical `lane-decision:<UUID>` identifiers, package realpath confinement, a
Git-primary policy owner, pre-effect pinning for self-retire receipt writes,
ambiguous-copy clear blocking with `lane_resolution_clear_package_ambiguous`,
and durable manifest/receipt mismatch blocking with
`lane_resolution_manifest_receipt_mismatch`.

A final fail-closed pass added exclusive package-directory creation,
`lane_resolution_preservation_package_exists`, lexical no-symlink checks for
package and record paths, pre-effect completion-receipt destination admission,
and immediate pre-delete package/manifest reobservation. Unsafe paths report
`lane_resolution_package_path_unsafe`, `lane_resolution_record_path_unsafe`, or
the bounded receipt-path gap without writing or deleting outside the records
owner.

The final reservation repair makes that receipt-path admission atomic for
conforming writers. Apply creates a hidden, non-JSON sidecar with
`O_CREAT|O_EXCL` before package creation or destructive effect. An existing
final receipt or sidecar blocks with `lane_resolution_receipt_path_exists` while
the branch, worktree, existing bytes, and package state remain unchanged.
Pre-effect failure and successful final receipt writing release the sidecar; a
post-effect receipt failure retains it alongside the stable decision and package
as explicit reconciliation state. The final writer still repeats no-symlink and
no-clobber checks.
