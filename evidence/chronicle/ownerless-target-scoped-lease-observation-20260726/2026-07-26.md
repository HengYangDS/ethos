## Root cause observation

The shared lease database satisfies the canonical schema. The exact budget
predecessor rows are valid and expired. Other historical subjects retain legacy
payload shapes that cannot be decoded as current `LaneLease` values. Ownerless
closeout currently selects and strictly validates every lease row before
filtering by the requested target, so unrelated historical damage blocks an
independent exact subject.

This is an observation-scope defect. It does not authorize migration or deletion
of the historical rows, and it does not weaken validation of the exact target.

## Executed regression evidence

Before the source change, the three new unrelated-legacy regression cases were
executed against the accepted implementation and failed exactly at whole-table
lease validation: state observation raised `state_unverifiable:lease`, fence
acquisition raised `lane_closeout_coordinated`, and native admission raised
`lane_resolution_ownerless_state_unverifiable`. The focused run reported
`3 failed`.

After the exact-subject query change, the same cases passed. The expanded suite
also locks the bound `where subject = ?` SQL and parameters, asserts unrelated
legacy payload bytes remain unchanged, and checks malformed exact-target rows
at fence acquisition and fenced re-observation. The three focused test owners
reported `111 passed` on Sunday, July 26, 2026.

## Ruling

Ownerless closeout must first validate the canonical lease schema, then query
with a bound exact `subject = ?` predicate, and strictly validate every returned
target row. Read observation and transactional fence acquisition must share that
helper. A malformed exact row remains fail-closed; an unrelated malformed row
cannot mint or block target coordination. No lease row is written by this
change.

After acceptance, any source effect still requires fresh Git observation, a new
decision and Chronicle binding, exact fence acquisition, accepted ancestry, and
the existing native postconditions. Prior Chronicle-invalid or observation-stale
decisions remain immutable and non-reusable.
