# Product Boundary Local State Evidence

## Claim

ETHOS product-boundary scanning rejects local workstation paths in active product
surfaces while preserving `.ethos/state/**` as ignored host-local runtime state,
not repository truth.

## Trigger signal

`candidate/dev` carried local proof projection files under
`.ethos/state/proof/*.json`. Those proof files contained absolute workstation
paths and made `ethos report --json` emit `local_workstation_path` gaps even
though `.ethos/state/**` is ignored local state and not a product surface.

## Net gain

- Keeps the product-boundary gate strict for active docs, config, source, tests,
  release metadata, OpenSpec specs, claims, and curated evidence.
- Stops ignored proof carry files from becoming false product-boundary truth.
- Preserves active `.ethos` configuration scanning while excluding only
  `.ethos/state/**`.
- Removes the unreachable duplicate prefix skip so the 100% coverage floor remains truthful.
- Adds a regression test for local proof records containing `/Users/...` paths.
