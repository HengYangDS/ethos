# Protected OpenSpec residue gate

ETHOS now scans configured protected branch Git trees for active OpenSpec change
carriers, not only the current checkout. Current protected roots block on active
carriers. Non-current protected branch residue is visible as advisory OpenSpec
shape-audit evidence so stale release-root history can be repaired deliberately
without misclassifying current accepted-root truth.

The live repository currently exposes advisory residue on `main:release_root` for
`ethos-release-hardening`; `dev` and `candidate/dev` remain free of active
OpenSpec carriers.
