# Publish Local CI Evidence Readmodel Evidence — 2026-07-09

## Claim

`ethos publish --json` now reports whether local CI fallback evidence is missing,
invalid, stale, or current for the current Git HEAD. The local fallback manifest
is produced by `tools/ci/scripts/run-local-ci.sh` after its stable-HEAD guard and
owner scripts complete.

## Boundary

This is a read-model and evidence-boundary hardening. It does not push to any
remote, does not claim hosted CI success, and does not convert generated local CI
artifacts into tracked repository truth. Repository truth remains source, tests,
schema, OpenSpec, claim, and HEAD-bound proof.

## Mechanism

- `tools/ci/scripts/run-local-ci.sh` writes
  `build/evidence/local-ci/fallback.json` with the stable HEAD and explicit false
  claims for hosted CI and remote publication.
- `ethos.domain.land_support` reads the manifest and projects
  `local_ci_fallback.evidence_status`.
- `ethos publish --json` threads one fallback package through the publication and
  local-submit package so the views agree.
- `campaign closeout` uses the same publication reducer with explicit repository
  root and current product HEAD binding, so campaign closeout cannot silently
  drop fallback evidence freshness while publish reports it.
- `system/schemas/kernel/campaign-closeout.schema.json` and schema samples include
  the new `evidence_status` contract.
- The archived OpenSpec delta uses the repository-required `## MODIFIED
  Requirements`, `### Requirement`, and `#### Scenario` shape so land-time
  archive closeout can verify it.
- Tests cover current, stale, and invalid manifests plus owner-script evidence
  emission.
- A failed HEAD-bound proof exposed a stale reducer call and a type-ratchet
  regression. The closeout fix preserves one reducer path instead of adding a
  second wrapper path, and the CLI lifecycle payload handling now casts JSON
  mappings at the edge.

## Design Judgment

The fix keeps local fallback evidence in the publication boundary instead of
creating a new status center. The next action now depends on evidence freshness:
missing, invalid, or stale manifests ask for local CI; a current manifest says
only that local fallback evidence is current at HEAD.
