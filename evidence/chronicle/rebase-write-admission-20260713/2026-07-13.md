# Rebase Write Admission Evidence 2026-07-13

## Observation

An owned Work Lane is allowed to replay through `ethos lane refresh-base`.
During Git rebase, `HEAD` is temporarily detached and may already name a
replayed commit. The lease, however, was issued against the named Work Lane
ref. Comparing `lease.expected_head` with the detached replay commit therefore
rejects a lawful write as `lease_head_stale`.

## Decision

Use two explicit observations rather than one overloaded `current_head`:

- `current_head` remains the detached Git `HEAD`, for diagnosis;
- `binding_head` is the named `refs/heads/<work-lane>` ref only when effective
  context came from Git's validated rebase `head-name`;
- ordinary writes continue to bind the lease to `HEAD`.

The named ref is never inferred from an arbitrary detached branch. If it cannot
be resolved, or it no longer matches the lease, admission remains fail-closed.

## Intended Evidence

The focused contract creates a real detached replay commit before invoking the
prewrite guard. It must prove that the detached observation differs from the
lease binding while sanctioned replay is admitted. Focused lint, format,
OpenSpec lifecycle, claim integrity, and lane lifecycle checks are required
before integration. A fresh candidate-head proof remains a separate condition
for candidate landing.

## Boundary

This change repairs local write admission for a sanctioned owned Work Lane
replay. It does not weaken protected-root admission, change a lease holder or
epoch, make detached branches generally writable, or grant authority beyond the
current local invocation.
