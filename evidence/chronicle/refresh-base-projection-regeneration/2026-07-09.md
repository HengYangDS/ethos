# Refresh-base Projection Regeneration Evidence

Date: 2026-07-09

## Judgment

`ethos lane refresh-base` now distinguishes repository truth conflicts from
tracked parity projection conflicts. If a stale Work Lane replay conflicts only
on `evidence/parity/*-shadow.json`, ETHOS keeps the candidate projection,
continues the replay, and returns `base_refreshed_projection_stale` with explicit
projection regeneration gaps and next actions. Any non-projection conflict still
aborts as `refresh_base_failed`.

## Boundary

This is intentionally narrow. It does not add a general conflict resolver, does
not treat generated evidence as semantic truth, and does not make a stale parity
shadow landable. It exposes the stale projection and requires regeneration plus
head-bound proof before landing.
