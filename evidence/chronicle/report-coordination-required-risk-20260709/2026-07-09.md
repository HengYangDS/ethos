# Report Coordination Required Risk — 2026-07-09

## Judgment

`ethos report --json` should not hide status-required Work Lane coordination
blockers behind a green scorecard. The scorecard now mirrors required
coordination gaps from repository audit/status for every governed repository
profile while keeping advisory foreign Work Lane signals non-blocking and
non-authorizing.

## Boundary

The change is a scorecard/read-model correction. It does not change Work Lane
ownership, does not authorize foreign cleanup, and does not make advisory
coordination gaps blocking. The required/advisory split is shared governed
repository semantics; profile changes proof depth and local quality floors, not
whether status-required coordination blockers are visible in report.
