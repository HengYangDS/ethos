# Repository Text Layout Completion — 2026-07-15

## Claim

Active repository text has one structural blank-line law: a single blank line
separates semantic blocks, while language-native formatters retain ownership of
the languages they understand.

## Boundary

- **Python:** Ruff and PEP 8 retain the top-level two-blank-line convention.
- **Markdown, TOML, YAML:** markdownlint MD012, Taplo, and Yamllint are the
  format authorities.
- **JSON, INI, Jinja, Shell:** the shared reader rejects leading, trailing, and
  repeated blank-line runs.
- **Excluded:** evidence and archived OpenSpec records are immutable history;
  active Changes and provider templates/projections are not exempt.

## Evidence

- The RED regression exposed repeated blank-line diagnostics before the scoped
  implementation converged; focused structural tests now cover one separator,
  leading/trailing/repeated rejection, Python heredoc preservation, and
  non-Python heredoc rejection.
- Native Markdown and YAML probes reject a two-blank-line run with MD012 and
  Yamllint `empty-lines` diagnostics.
- The active GitLab template and generated `.gitlab-ci.yml` projection now have
  matching one-blank-line structure.
- The focused structural/documentation/artifact-topology suite passed 125 tests.
  Focused adopter lifecycle/scope regressions also passed: lifecycle 1, proof
  contracts 33, scope 17, and OpenSpec contracts 2.
- Config, Markdown, Shell, format-selection, and repository-hygiene owner
  scripts passed. Strict OpenSpec validation passed 10 of 10 items; lifecycle,
  claims, source-budget, and parity reports were clean before archival.
- The 190-line temporary source-budget allowance is measured from the staged
  carrier rather than guessed from the untracked tree: Python tooling 66,
  tests 113, and Shell wiring 11. It preserves the global debt cap as a named,
  removable record.

## Decision

The shared reader is deliberately a complement, not a replacement. It does not
interpret Python layout or embedded Python heredocs; it supplies the missing
common boundary for active text carriers without adding a private governance
plane.
