# Retire owner boundary

ETHOS tightened landed Work Lane retirement so visibility and merge status no
longer imply authority. `retire-landed` now requires the runtime actor to match
the active Work Lane lease owner before planning or applying retirement. Missing
lease ownership and actor mismatch report `foreign_work_lane_retire_authority_required`.

This keeps the existing lease as the source of authority and avoids adding a new
CLI surface or ownership store.
