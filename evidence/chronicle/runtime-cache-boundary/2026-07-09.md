# Runtime Cache Boundary Chronicle

## Claim

ETHOS keeps configuration policy, runtime caches, and generated proof evidence
physically separate: pytest policy stays in `pytest.ini` and
`.config/checks/pytest/policy.toml`; pytest runtime cache lives under ignored
`build/runtime/tool-cache/pytest`; generated test evidence remains under
`build/evidence/quality/tests`.

## Trigger signal

A live repository inspection showed ignored pytest cache material under
`.config/checks/pytest/.pytest_cache` and a tracked
`.config/checks/pytest/.gitignore` sidecar. The sidecar existed only because a
runtime cache had been placed inside the configuration plane.

## Net gain

- Removes one sidecar ignore file instead of adding another policy entity.
- Makes `.config/checks/**` declarative and cache-free.
- Aligns pytest cache with the generated-artifact topology's runtime/build homes.
- Preserves pytest-native root discovery through `pytest.ini`.
- Keeps JUnit and coverage evidence under `build/evidence/quality/tests`.
