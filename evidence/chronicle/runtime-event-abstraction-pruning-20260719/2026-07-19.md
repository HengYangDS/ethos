# Runtime and event abstraction pruning

## Fact

ETHOS carries lane Runtime-composition forwarding and event declarations that
have no distinct semantic owner, producer-consumer flow, or extension contract.

## Boundary

This change deletes those abstractions while preserving lifecycle mutation
safety, Chronicle evidence, pure projections, Git hooks, and explicit adapter
boundaries. It does not introduce DI, an event bus, a plugin manager, aliases,
wrappers, shims, or compatibility behavior.
