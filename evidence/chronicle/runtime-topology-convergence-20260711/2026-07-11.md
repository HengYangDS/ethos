# Runtime Topology Convergence Chronicle

## Judgment

ETHOS now gives every repository-owned Python producer one semantic runtime
boundary. The source environment is bound to the executing checkout at
`build/runtime/venv`; dependency downloads are a separately declared host or
CI cache concern. A cache therefore accelerates execution without becoming a
source tree, Work Lane lease, evidence carrier, or authority surface.

The runtime bootstrap is the only product-owned adapter for that boundary.
Installed hooks, owner scripts, GitHub and GitLab templates and projections,
and both local provider emulators enter through it or through a deliberately
bounded interpreter override. Product-owned paths no longer fall back to a root
`.venv` or use bare `uv run` as an unbound producer path. The generated-artifact
topology audit enforces this executable invariant while allowing pre-existing
ignored root environments only as non-authoritative migration residue.

The OpenSpec carrier is archived at
`openspec/changes/archive/2026-07-11-runtime-topology-convergence-20260711`;
its one modified requirement and three added requirements are fused into the
live repository-governance specification.

## Boundary

This is local implementation and verification evidence only. It does not
assert hosted GitHub or GitLab execution, remote GitLab publication, global
shared-environment authority, automatic deletion of any existing root virtual
environment, or authority over foreign Work Lanes. Final lane proof, candidate
landing, accepted-root closeout, retirement, and local publish readiness remain
separate governed transitions.
