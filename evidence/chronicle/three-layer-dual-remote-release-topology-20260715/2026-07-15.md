# Three-Layer Dual-Remote Release Topology — 2026-07-15

## Decision

ETHOS declares three separate release roles: local verification and installation
remain remote-independent; GitLab is the organizational primary publication
source; GitHub is an independently configured mirror for update and
distribution continuity.

A GitHub mirror may be observed as an update and distribution fallback when the
GitLab primary is unavailable. It does not establish GitLab primary
publication, GitLab hosted CI, a remote push, or repository proof.

## Implemented Boundary

The tracked release policy projects the roles and their provider surfaces.
`ethos publish` observes primary and mirror availability separately, remains
read-only, and reports explicit non-claims. If the optional `github` remote is
absent, the mirror state is `unconfigured`; local verification remains valid and
no adopter must configure GitHub.
