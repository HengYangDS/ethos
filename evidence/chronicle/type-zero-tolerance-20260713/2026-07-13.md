# Python Type Zero-Tolerance Evidence 2026-07-13

## Claim

ETHOS treats Python type checking as a fail-closed, zero-diagnostic quality law
for every declared governed package. Tool availability and output integrity are
part of the verdict: an unknown execution is a blocking state, never a clean
count.

## Decision

The former `packages/ethos` diagnostic ratchet has been removed. The single
policy now declares both `packages/ethos-core` and `packages/ethos` as
zero-tolerance targets. The `ty` adapter preserves process outcome and blocks
missing tools, launch failures, non-zero indeterminate output, and malformed
terminal results with a stable execution gap. No baseline, ignore, `noqa`, or
compatibility surface was introduced.
