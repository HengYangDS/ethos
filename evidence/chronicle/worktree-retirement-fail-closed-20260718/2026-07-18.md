# Fail-Closed Ordinary Work Lane Retirement — 2026-07-18

## Claim Boundary

This record covers only ordinary local retirement for a clean, owned, linked
Work Lane and ordinary blocking of unbound `work/*` refs. It does not claim a
recovery package, deletion admission, exceptional resolution, foreign-lane
authority, migration, remote publication, GitHub state, GitLab state, hosted
CI, or portfolio convergence.

## Design Decision

Planning observations are not deletion authority. At effect time the selected
linked checkout itself is reobserved for its registered path, ref, checkout
HEAD, and tracked/untracked status. ETHOS calls normal `git worktree remove`
without `--force`; only after that succeeds does the available controlling
checkout compare-and-delete the named ref at the expected head. A changed ref
after worktree removal is reported as an explicit blocked residue, not restored
or deleted by inference.

An unbound ref has no locally observable worktree, uncommitted-file inventory,
or confirmed owner. The ordinary unbound command therefore blocks with
`unbound_retire_requires_exceptional_deletion_admission`; absent registration
is not abandonment evidence.
