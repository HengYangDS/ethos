## ADDED Requirements

### Requirement: Material Change scope admission

A future ETHOS implementation SHALL bind each changed adopter material path to
at least one valid ETHOS companion beside an official active or archiving
OpenSpec Change. The companion SHALL NOT alter official OpenSpec schema.


#### Scenario: Scope work remains separately governed
- **WHEN** portable material scope admission is not implemented
- **THEN** universal lifecycle remains an independent OpenSpec obligation
- **AND** no unrelated Change or method package is treated as scope authority.
