## ADDED Requirements

### Requirement: Isomorphic Governance Profile Contract

ETHOS SHALL define self-governance and product-adopter governance as profiles of one kernel chain rather than separate product forms.

#### Scenario: Shared governance shape is validated

- **WHEN** ETHOS validates governance profile contracts
- **THEN** both profiles declare the shared kernel chain, trust lifecycle, capability graph, run steps, truth sources, and advisory projection boundary
- **AND** allowed differences are limited to authority binding, profile configuration, adapter binding, strictness, and rollout policy.
