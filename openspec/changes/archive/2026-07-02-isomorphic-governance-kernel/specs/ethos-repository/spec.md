## ADDED Requirements

### Requirement: Governance Profile Report

ETHOS SHALL report the shared and differing parts of self-governance and product-adopter profiles through schema-validated repository quality output.

#### Scenario: Governance profile drift is surfaced

- **WHEN** schema validation or quality reporting evaluates governance profiles
- **THEN** missing shared kernel, lifecycle, capability, truth-source, or advisory-projection fields produce required gaps
- **AND** adopter-specific bindings remain explicit profile differences rather than alternate kernels.
