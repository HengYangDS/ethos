# Design

This closeout is a binding carrier, not another implementation batch. It records
that ETHOS has moved from roadmap-only posture to an active baseline plus
explicit future adapter sequencing.

The closeout preserves the ETHOS kernel:

```text
Authority -> Subject -> Commitment -> Change -> Evidence -> Claim -> Chronicle
status -> plan -> prove -> land -> publish
```

External mechanisms enter only through bounded forms:

- GitHub and GitLab are provider projections over one repository contract.
- Local CI emulators and fallback bundles are local evidence classes.
- OpenSpec is mandatory official governance; ETHOS repo-local validation runs
after official validation.
- Format, lint, architecture, C4, runbook, MCP, local-state, release, and
security tools become active only when owner surfaces and proof coverage exist.
- Superpowers and other method packs are replaceable agent discipline, not
runtime or proof substrate.
- Nox, Pixi, Pants, task ledgers, Dagger, OSV, image scanners, and external
signing are profile or adapter work until later accepted proof activates them.

The closeout evidence intentionally separates local proof, candidate landing,
accepted-root closeout, hosted CI observation, and remote publication. A local
manifest or emulator output is not a hosted-provider success fact.

Rollback is documentation and evidence rollback: revert the closeout carrier,
claim digest, chronicle append, and roadmap completion boundary. Implemented
owner gates remain governed by their own archived carriers and tests.
