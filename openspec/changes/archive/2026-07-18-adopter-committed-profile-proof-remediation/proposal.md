work did not become current candidate truth. This active Change is therefore
the sole landable carrier for the behavior: it brings candidate-tree policy
resolution into the current candidate baseline and proves it without weakening
the active quality floor.

  parity evidence and obtain an exact-HEAD executed proof.

  that the current candidate already contains this behavior.
