## Why

The accepted repository has a live cohort of foreign and unbound `work/*`
references whose current state cannot be closed by branch count alone.  Each
reference can carry a different lease, dirty overlay, claim binding, ancestry,
and semantic delta.  The user has authorized local takeover work, but that
instruction does not turn visibility into wildcard mutation authority.

The cohort therefore needs one owned, evidence-bound closeout carrier that
re-observes every exact target, preserves unreconciled work before any
irreversible action, replays only still-valid product intent on the current
candidate baseline, and records why any remaining target is blocked.

## What Changes

- Add an active repository-governance decision carrier for the July 18, 2026
  Work Lane cohort, with an exact current matrix, claim, Chronicle, and
  bounded local closeout plan.  This first carrier promotes the accepted
  decision foundation; it does not perform foreign-lane effects before that
  foundation is accepted.
- Require every exceptional foreign or owner-uncertain lane effect to use a
  fresh exact observation and a native two-phase resolution decision; ordinary
  handoff remains preferred for a valid holder.
- Direct follow-on successor lanes to preserve every dirty or unbound delta
  before retirement, then replay only behavior that remains absent from the
  current accepted/candidate contract.
- Require each follow-on semantic replay to use the normal `status -> plan ->
  prove -> land -> accepted-root closeout` lifecycle and retain an explicit
  receipt for every retire, preserve-retire, or block result.
- Repair shadow-parity external execution so a current checkout-bound runtime
  takes precedence over a stale root `.venv` that cannot import ETHOS.
- Admit only this carrier's exact Chronicle matrix path through the existing
  fail-closed JSON format-selection policy.
- Keep local closeout, local CI fallback evidence, remote reconciliation,
  remote push, and hosted CI as separate evidence planes.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `repository-governance`: subject=authorized-work-lane-cohort-closeout;
  reuse=extend; change=modify; facet:lifecycle=observation,resolution,retirement;
  facet:surface=openspec,claim,evidence,docs,cli; facet:authority=git,lease,
  claim,chronicle,executed-proof. An authorized cohort closeout must bind every
  exceptional action to a complete lane observation and an exact target rather
  than inferring authority from a visible foreign lane.

## Impact

- This Change's OpenSpec artifacts, scope, claim, Chronicle, exact JSON carrier
  admission, and local resolution matrix.
- A current local Work Lane closeout plan and, only where audit proves a product
  behavior is missing, focused source and regression-test changes on the owned
  Work Lane.
- Native lane-resolution receipts and local proof evidence; no foreign worktree
  is edited as part of the audit.

## Out Of Scope

- Raw branch/worktree deletion, `git stash`, wildcard cleanup, or foreign-lane
  mutation merely because it appears in status.
- Remote probing, reconciliation, force-push, ordinary push, release
  publication, or hosted-CI success claims.
- Treating a digest, old receipt, or historical lane matrix as proof that a
  mutable current target may be retired.
