## Why

Recovered `work/*` branches are evidence sources, not a merge queue. A branch
may contain a still-useful behavior, a behavior already accepted through a
different lineage, a deliberately unadmitted product proposal, or an active
holder-owned delta. Deleting or preserving it does not establish which case
applies.

This first absorption wave records those distinctions for the direct-candidate
cohort and replays only two current missing behaviors: a checkout-bound hosted
Python runtime and process-local Git fsmonitor isolation. It records the
already-accepted security, Docker-context, and raw-coverage behaviors without
reintroducing their historical topology.

## What Changes

- Add a bounded semantic-absorption carrier, claim, Chronicle, and plan.
- Materialize the hosted bootstrap runtime before owner scripts use it.
- Keep every test-launched Git subprocess independent of host fsmonitor while
  preserving existing indexed Git configuration entries.
- Record current-equivalent, deferred, and holder-bound source-lane outcomes.
- Require accepted closeout evidence before source-lane retirement.

## Capabilities

- `repository-governance`: subject=work-lane-semantic-absorption;
  reuse=extend; change=modify; facet:lifecycle=validation,archive;
  facet:surface=ci,tests,openspec,evidence,docs;
  facet:authority=source,test,openspec,claim,evidence.

## Out Of Scope

- Wholesale merge, cherry-pick, raw ref deletion, `git stash`, force push, or
  retirement of an unabsorbed source lane.
- Writing a foreign worktree, assuming a missing lease transfers authority, or
  changing a valid external holder's lane.
- Admitting the optional container-contract proposal without a current
  product/adopter decision.
- Remote publication or hosted CI success claims.
