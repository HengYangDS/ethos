# terminal-convergence

The sole active Change and task-progress owner for the terminal-convergence
Campaign. `tasks.md` remains authoritative until every terminal obligation is
implemented and proved; phase decomposition in `design.md` expresses dependency
and acceptance boundaries without creating another task ledger or active Change.
The accepted capability specs already carry the terminal behavior. The final
carrier therefore declares `skip_specs`; its retired delta files remain available
in Git history rather than being replayed over newer canonical requirement names.
