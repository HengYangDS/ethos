## Why

Current proof uses the Git-native Attestation set, yet a separate quality gate
requires obsolete tracked evidence directories and reports their shape as
freshness. Root history, a one-file documentation directory, profile carriers
and retention declarations perpetuate an authority model that has no current
producer. They add maintenance without proving a current proposition.

## What Changes

- **BREAKING**: retire tracked historical evidence and its directory-derived
  freshness gate, layout declaration, unused profile carriers and selectors.
- Preserve current Attestation selection, exact proof bindings and Git history.
- Absorb the duplicate evidence explanation into its existing documentation
  owner and remove the obsolete documentation root and required-path rules.
- Close current configuration, source-budget, specification and packaging
  references without moving records into another archive.

## Capabilities

### Modified Capabilities

- `repository-governance`: proof and documentation independent of historical
  workspace evidence directories.
- `adapters`: current Attestations selected solely by their existing Git set.

## Impact

Evidence topology providers, profile and audit declarations, gate registry,
package resources, historical files, documentation and focused regressions.
No Attestation object-layout change, history rewrite, adopter mutation, worktree
retirement, runtime activation, new registry or replacement proof state machine.
Docstring enforcement and root-quality configuration placement are separate work.
