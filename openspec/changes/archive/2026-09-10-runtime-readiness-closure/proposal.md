## Why

Exact full proof is intermittently blocked by hook-contract children that import
runtime selection and policy machinery merely to render immutable launchers.
Timeout escapes the public binding reader. Two package tests also resolve an
isolated offline build environment despite an available locked project supply.
These boundaries repeatedly prevent already reviewed work from being accepted.

## What Changes

- Keep pure hook-contract queries free of runtime-selection and policy imports;
  move actual observation and authority consumers to their dedicated semantic owner.
- Move pure interpreter-path projection into the existing runtime filesystem
  owner and migrate consumers without compatibility re-exports.
- Return exact timeout diagnostics without arming admission, automatic reinstall
  or extending the deadline. Later explicit observation may recover.
- Bind package identity tests to the existing locked interpreter and build
  dependencies, matching production delivery instead of ambient offline cache.

  preserve precise unavailable evidence without importing unrelated authority.

## Impact

Hook binding, runtime filesystem and layout consumers, package/runtime tests and
existing terminal plan. No new dependency, registry, cache, persistent contract,
second runtime or lifecycle. The archived terminal projection remains unchanged.
