## Why

Drawing architecture currently changes ETHOS product source, package tests,
quality checks and archive behavior. The user requires zero drawing-induced
integration in source repositories. The existing Publisher package and terminal
projection therefore have no legitimate ETHOS product owner.

## What Changes

- Remove the Publisher integration, dedicated export, terminal artwork inputs
  and their source-test and archive callers.
- Preserve ordinary product documentation, generic producer relations, native
  archive reference relocation and the npm launcher acceptance.
- Transfer unique editorial inputs to the independent architecture-publications
  repository before deletion. Keep accepted deliveries and Git history intact.

## Capabilities

### Modified Capabilities

- `adapters`: retire the optional source-owned Publisher integration.
- `assistant-projections`: retire terminal drawing export, retaining Agent projections.
- `quality`: move diagram-only coverage and artwork obligations outside ETHOS proof.

## Impact

The change removes drawing-specific source and tests and repairs their existing
callers. It does not change the governance kernel, source meaning, supported
platforms, credentials, release history or another contributor's Lane.
