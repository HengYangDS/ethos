# Design

The governed repository expresses only per-action assurance depth. Provider
configuration is system-local and protected from the invoking identity. Publish
constructs an exact request from Git and gate policy facts; receipt admission
verifies its binding and an SSH signature against the protected anchor.

The reference adapter copies its executable and runtime outside the requesting
checkout. It allows exactly one configured remote and commit, creates an
independent checkout, requires sandboxing, re-executes the normal proof floor,
and publishes only a signed receipt. It does not accept arbitrary commands or
manage a service lifecycle.

Proof and report project the selected evidence class without making a
publish-only policy block other transition actions.
