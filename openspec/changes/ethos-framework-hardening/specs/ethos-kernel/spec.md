# ETHOS Kernel Delta

## Requirements

- ETHOS SHALL serialize invalid action graphs with validation gaps instead of
  recursive fallback.
- ETHOS SHALL bind proof summaries to evidence digests and provenance
  envelopes.
- ETHOS SHALL expose docs registry, assistant projection, and campaign
  hypotheses under the `ethos` command plane.
- ETHOS SHALL gate apply-mode land and publish readiness on explicit
  authorization and expected HEAD.
