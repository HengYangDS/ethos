# ETHOS Kernel Delta

## Requirements

- ETHOS SHALL validate command JSON and protocol schemas with a tracked schema
  registry.
- ETHOS SHALL execute selected gates through the action graph and bind results
  into evidence.
- ETHOS SHALL expose release readiness, commit signature policy, and GitLab
  governance under `ethos quality`.
- ETHOS SHALL keep adoption profiles as projections outside the kernel.
- ETHOS SHALL expose self-evolution hypotheses from a tracked ledger.
- ETHOS SHALL expose MCP server capability as an adapter descriptor, not a truth
  store.
