## ADDED Requirements

### Requirement: Hosted Readiness Report Observes Executed Proof Artifacts

ETHOS SHALL execute the hosted HEAD-bound proof before producing the readiness
report that is combined with that proof, so the report observes coverage and
proof state generated by the same exact-HEAD execution.

#### Scenario: Clean hosted checkout reports post-proof readiness

- **GIVEN** a clean hosted checkout has no pre-existing coverage XML or executed
  proof receipt
- **WHEN** `tools/ci/scripts/run-head-bound-proof.sh` evaluates an expected HEAD
- **THEN** repository audit executes before the proof attempt
- **AND** `ethos prove --execute --expect-head` executes exactly once before
  `ethos report --json`
- **AND** the report evaluates coverage and proof state produced by that same
  proof attempt
- **AND** the compact receipt is successful only when audit, the post-proof
  report, and proof are all successful
- **AND** proof failure diagnostics and proof/readiness artifacts remain retained
- **AND** no separate full-test producer, automatic retry, weaker timeout, worker
  change, or GitLab change is introduced.
