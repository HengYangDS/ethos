## Boundary

The hosted proof entrypoint owns preparation for the process it starts. Native
installers own version, checksum and installation mechanics. Forge jobs remain
thin callers. Successful preparation in one job says nothing about another job.

## Repair

Use the existing scanner installer before invoking proof, then the existing SCC
installer. Preserve each nonzero exit and diagnostic in the shared supply-failure
receipt; clear previous proof and test artifacts before either operation. Send
installer chatter to diagnostics so stdout remains one machine-readable result.
Do not copy supply policy, add a registry or relax real scanner tests.

## Deferred Boundaries

The pre-existing Linux installer is not generalized into a new cross-platform
supply framework here. Existing supported macOS preparation recognizes its exact
installed scanner. Broader native supply and hermetic clean-host support remain
in the existing terminal plan, not silently claimed by this fix.
