# Proposal

## Why

Package acceptance creates its console environment from the project interpreter, then isolates
native Python discovery. A Framework interpreter cannot become an immutable runtime image, and
the isolation hides the installed standalone supply. Full proof reproduces this activation failure.

## What Changes

- Select a congruent copyable interpreter through the existing native image-source owner before
  host isolation, and use it for the installed console environment.
- Preserve the locked project interpreter as the dependency-supply owner.
- Retain offline installation, host independence, runtime admission and cleanup requirements.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. This repairs the existing package-acceptance caller without changing product contracts.

## Impact

Only the existing delivery acceptance owner and its regression change. No Python installation,
project constraint, default interpreter, existing environment, adopter runtime or release binding changes.
