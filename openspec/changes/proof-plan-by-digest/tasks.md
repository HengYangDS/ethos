# Tasks

## 1. The cited record

- [ ] 1.1 Write the plan as a proof artifact and issue the record in the cited form when its plan
      is too large to carry. Done when a proof of a lane with about 1,400 changed paths records
      under 2,000 bytes at the unchanged bound, the plan read back through the record equals the
      plan that ran, and a proof of a small lane still carries its plan.
- [ ] 1.2 Resolve a cited plan and refuse each wrong case by name. Done when an absent file, altered
      bytes and a write over other bytes each fail closed with their own gap code, and selection
      and the repository-transition admission give the same answer.
- [ ] 1.3 Keep the by-value form readable. Done when a record written in that form reads and is
      selected with no plan file in the store.
- [ ] 1.4 Carry the cited proof through a landing. Done when the product's archive, landing and
      closeout of such a lane, on a proof issued through the product's issuance, re-validate
      both of the landing's records whole.

## 2. Retention and the record of the change

- [ ] 2.1 Teach retention the plan file's kind. Done when a plan file is kept while a record cites
      it and deleted only when its proof leaves.
- [ ] 2.2 State the change and its rollback limit in the changelog. Done when the unreleased
      section names the cited form, the unchanged bound, and that an earlier release cannot prove
      a head whose plan exceeds the bound.
