# Tasks

## 1. Apply

- [ ] 1.1 Restore tombstones before any scan. Done when a test shows an interrupted apply's
      tombstones restored by the next preview, a re-created name kept beside its tombstone, and a
      rerun deleting the rest of a half-deleted lane unit with its receipt last.
- [ ] 1.2 Delete only plan items a fresh scan still selects. Done when a test shows a changed, young
      or newly named item kept, an absent planned file counted as done, and a schema-1 plan refused.
- [ ] 1.3 Defer on another ETHOS interpreter of the repository. Done when a test shows a batch
      deferred by a non-selected runtime's process and by an unreadable listing, and not by another
      repository's process, a hook run or a shell naming a `.venv`.
- [ ] 1.4 Compare under the custody lock. Done when a test shows a set swap or an accepted advance
      during the compare restoring what it names, a held custody lock deferring the batch, and a
      custody-free swap waiting for the lock.
- [ ] 1.5 Receipt each run. Done when a test shows the receipt's per-kind counts and reasons, the
      live-token fact, and a plan with a deferral-free receipt deleting nothing.
- [ ] 1.6 Re-link adopted records. Done when tests show a writer restoring a record renamed away
      before its read and after it.

## 2. Command

- [ ] 2.1 Expose the apply. Done when the preview's `next` names the destructive apply, and an apply
      without `--authorize` or `--expect-plan`, or with `retention.lock` held, refuses and deletes
      nothing.
- [ ] 2.2 Correct the docs. Done when the command reference and the local-state architecture
      describe the apply.
