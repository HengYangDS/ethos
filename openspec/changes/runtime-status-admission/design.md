## Invariant And Counterexample

Runtime freshness and optional commit policy are independent constraints. A
declared adopter or an installed runtime can require repair without declaring
commit grammar. The public reader must expose that gap and the runtime owner's
exact next action; a PASS from one capability cannot erase another's failure.

The original counterexample is the Proxy payload named in the canonical plan:
its runtime source is stale, yet top-level status is PASS and offers landing.
Reproduce the same relation with an isolated native runtime, not adopter writes.

## Owner And Applicability

`hook_runtime_binding` continues to own source identity, launcher checks and the
repair command and whether the installation obligation applies. The existing
status function combines independently applicable observations. The repository
profile declares adoption; a managed hook generation or runtime storage supplies
an installation to inspect even when its selector is damaged. Applicability
cannot depend on successful validation. A plain repository with neither must
not acquire an installation obligation merely from inspection.
Commit-policy absence remains `not_declared` with no policy gaps.

Runtime recovery takes precedence over a later source effect. Invalid policy
still reports its own failure and recovery; no gap is discarded and no parser,
cache, state store or second command builder is introduced. Read-only status
keeps its existing process-exit contract; its JSON verdict conveys readiness.

## Verification

Public tests distinguish no-policy stale/current installations, missing adopter
installation, missing launcher, observation timeout and genuinely unadopted
inspection. Keep existing declared-policy and pending-acceptance tests. The
former implementation must fail the no-policy verdict/action assertions.
Run affected reader, binding and closeout checks before static and exact proof.

## Boundary

This is status correction, not proof that a source transition or installation
occurred. Exact proof, archive, acceptance, installation, publication and lane
retirement each retain their existing independent admission and evidence.
