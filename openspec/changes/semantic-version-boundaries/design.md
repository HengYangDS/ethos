## Principle

A name describes responsibility. A version distinguishes interpretations only
where independently produced or persisted input crosses a compatibility boundary.
Source history and exact digests identify changes without adding a second manual
revision counter. A validator's existence alone does not establish necessity.

## Repository-Wide Visibility And Source Ownership

The private-module example is a counterexample to a global obligation, not a
filename exception. The existing layout gate owns Python import visibility
throughout product, tests, tools and skill code. It resolves Import and ImportFrom
(including aliases and relative spelling) to the actual module identity. A private
symbol belongs to its defining module. A private module belongs to its immediate
semantic package: that package's direct modules may use it; a different public
subpackage does not inherit access. A private package's own subtree may use its
internals. Component-wise containment prevents similarly prefixed names from
acquiring access. Dunder protocol names are distinct from double-leading-only
private names. Import spellings do not create a new owner or make a private public.

Public means available at the declared Python boundary, not automatically a
stable external SDK promise. Exposing a name requires a real consumer contract;
renaming every helper public would conceal rather than fix coupling. The existing
Ruff member check owns attribute access and the native relative-import rule owns
absolute spelling. Layout checks own repository-specific module/symbol boundaries;
layer contracts remain with import-linter. Documentation must describe each tool's
actual coverage, not claim that one lint rule establishes all encapsulation.

Remove the shared `_resources` entry instead of renaming it. Its two consumers
have different authority: gate defaults belong to the interpreting source/package,
explicit gate paths must exist and validate, while skill manifests use the existing
schema owner's interpreter-bound schema. A missing requested path may not silently
select another declaration. Caller CWD or adopter schemas cannot redefine defaults.
Do not add a public resource utility, compatibility alias or second schema reader.

The inventory covers all Git-selected Python files, not only product code.
Current additional gaps include one relative import, missing module docstrings,
incomplete declared layer coverage and undocumented external API promises. Scope
and findings remain in the sole terminal plan until each has actual gate evidence.
This batch settles import visibility and related source ownership; it does not
claim arbitrary dynamic access or every quality obligation is already proved.
