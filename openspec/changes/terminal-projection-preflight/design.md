## Failure Left-Shift

Call the official export function from the architecture gate with the gate's
selected root and captured HEAD. A stale or missing source yields the exporter's
actual cause and blocks dependent heavy tests, coverage and packaging. Valid
export reports its commit, tree and input digest. Native render drift remains an
independent failure. Uncommitted source is not a committed export; the existing
actual-source regression still tests proposed bytes before commit.

The same dependency closure runs after archive, so future canonical changes
cannot defer this known failure until the full test suite. Archive still needs
semantic reconciliation where meaning changed; this repair neither auto-approves
digests nor changes the official archive effect.
