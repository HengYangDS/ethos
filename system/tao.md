# ETHOS Tao

> The irreducible value axioms. Everything mechanical follows from these and lives
> elsewhere: design derivations in `system/derivations.md`, product description in
> `docs/`, durable machine contracts in `system/*.toml`. Human-authored Markdown,
> not machine state.

## Root Verse

> 道隐无名，几动于微，法乎自然；
> 生一启元，分二判势，孕三冲和；
> 万象昭幽，度协畛域，枢得环中；
> 物遂其性，化育无穷，是谓玄德。

This verse is the root generative constraint for ETHOS. It is not branding,
ornament, or a provider-specific slogan. Every durable surface must be derivable
from the same movement: hidden authority, early signal, natural fit; one kernel,
necessary distinctions, reconciled bindings; visible state, domain-fit measure,
centered pivot; boundary-preserving growth.

## Axioms

1. **Purpose.** A governance product is worth only the invalid states it makes
   unreachable.
2. **Trust.** No claim without authority or proof.
3. **Form.** The answer must be small enough for a human to trust and structured
   enough for a machine to execute.
4. **Parsimony.** An entity is justified only when it owns a distinct semantic
   obligation; otherwise merge, project, or delete it.
5. **Natural fit.** Each tool, model, host, framework, protocol, repository, and
   evidence carrier keeps its native nature; ETHOS governs the boundary and
   promotion path instead of absorbing it into a false center.

Axiom 1 is the telos. Axioms 2–5 each name a class of invalid state it forbids —
the unproven, the untrustable-or-inexecutable, the undermotivated, and the
miscentered. Every rule elsewhere is a mechanism that eliminates one of these
classes; see `system/derivations.md`.

## Operational Reading

| Verse movement | ETHOS obligation | Forbidden failure |
| --- | --- | --- |
| 道隐无名，几动于微，法乎自然 | Keep authority deeper than named tools, observe small drift early, and fit governance to repository reality. | Tool-centered ontology, ignored weak signals, imposed provider shape. |
| 生一启元，分二判势，孕三冲和 | Start from one kernel, split only discriminating boundaries, reconcile through explicit evidence and claim bindings. | Parallel truth centers, decorative symmetry, unbound compromise. |
| 万象昭幽，度协畛域，枢得环中 | Make hidden state legible, measure within the proper domain, and keep the kernel chain as pivot. | Opaque state, cross-domain metrics, scorecards becoming authority. |
| 物遂其性，化育无穷，是谓玄德 | Let Git remain Git, OpenSpec remain governance, local models remain models, assistants remain projections, and future frameworks enter by contract. | Adapter capture, model/vendor lock-in, host-local state promoted as truth. |
